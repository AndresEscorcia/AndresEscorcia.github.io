No convertir automáticamente cada palabra de Computrabajo en una afirmación de dominio avanzado. En el portfolio, las tecnologías deben asociarse a proyectos, funciones o evidencia concreta cuando sea posible.


## Caso real incorporado: TicsAGP

Se incorporó como proyecto destacado el repositorio público `AndresEscorcia/TicsAGP`, específicamente `T1Tics.ps1`.

El análisis del script permite documentar evidencia concreta de:
- PowerShell.
- Automatización de preparación de equipos Windows.
- Chocolatey para instalación/actualización de software.
- Validación de conectividad.
- Manejo de errores y progreso.
- Gestión dinámica de una lista de programas.
- Configuración de políticas de Windows.
- Cambio de nombre de equipo y zona horaria.
- Configuración de wallpaper corporativo.

Antes de usarlo como pieza pública definitiva, revisar y sanear las referencias a infraestructura interna que aparecen en el código.


## Criterio editorial del portfolio

El sitio está redactado en **tercera persona o en formulación profesional neutra**. No debe utilizarse primera persona para describir experiencia, competencias o proyectos.

Ejemplos:
- Incorrecto: "Mi experiencia..."
- Correcto: "La experiencia profesional..."
- Incorrecto: "Puedo aportar..."
- Correcto: "Áreas de aporte profesional..."
- Incorrecto: "Estoy interesado..."
- Correcto: "Perfil orientado a oportunidades..."

Cuando un proyecto sea colaborativo, debe indicarse como tal y no atribuirse individualmente todo el trabajo.
