PROYECTO 01 · CASO REAL · POWERSHELL

Automatización de preparación de equipos TI.

Desarrollé un script de PowerShell para automatizar tareas de preparación y estandarización de equipos Windows en un contexto asociado a Agropaisa, Agromilenio y Ducol.

Ver código en GitHub ↗ ← Volver al portfolio

Qué resolví

Centralicé tareas que normalmente tendrían que ejecutarse manualmente durante la preparación de equipos: comprobación e instalación de Chocolatey, validación de conectividad, instalación o actualización de aplicaciones y configuración de parámetros de Windows.

Automatización implementada

Gestión de paquetes

Integré Chocolatey para instalar y actualizar una lista de aplicaciones.

Comprobación de conectividad

Incluí comprobaciones de conectividad antes de ejecutar determinadas tareas.

Progreso y errores

Implementé seguimiento del progreso y registro de programas que presentan errores durante la instalación.

Gestión de programas

Incorporé opciones para consultar, agregar y eliminar elementos de la lista de programas.

Configuración de Windows

El script permite seleccionar un fondo asociado a Agropaisa, Agromilenio o Ducol y configurar parámetros relacionados con el wallpaper.

También contempla cambio de nombre del equipo, zona horaria de Colombia, sincronización con time.windows.com, desactivación del hotspot móvil y ajustes sobre servicios de gaming.

Qué demuestra este proyecto

Creación de scripts en PowerShell: trabajé con funciones, parámetros, ciclos, condiciones, manejo de errores y un menú interactivo.

Automatizacion de TI: convertí tareas repetitivas en una rutina más reproducible.

Administracion de Windows: automatizé cambios sobre propiedades y configuración del sistema mediante PowerShell.

Gestión de paquetes: integré Chocolatey para facilitar la instalación y actualización de software.
